# 技能市场流式调试功能使用指南

## 📋 功能概述

技能市场的流式调试功能允许开发者实时测试技能，查看 AI 响应、工具调用过程和执行统计。

## 🚀 快速开始

### 1. 启动服务

```bash
# 后端服务
cd backend
python main.py

# 前端服务（另开一个终端）
cd frontend/aigc-frontend
npm run dev
```

### 2. 访问调试页面

在浏览器中打开：
- 开发环境：http://localhost:5173/debug
- 或者通过导航菜单：调试系统 → 技能调试

### 3. 使用流式调试

1. **选择调试模式**
   - 点击右上角的"流式模式（推荐）"按钮

2. **填写技能信息**
   - 技能名称：输入技能标识符（如 `todo-master`）
   - 技能内容：粘贴或编辑 SKILL.md 内容
   - 测试查询：输入要测试的问题

3. **开始调试**
   - 点击"开始调试"按钮
   - 实时查看 AI 响应和工具调用
   - 查看执行统计（成本、耗时、轮次）

## 📊 界面说明

### 左侧编辑区
- **技能名称**：技能的唯一标识符
- **技能内容**：Markdown 格式的技能定义
- **测试查询**：用于测试技能的问题

### 右侧结果区
- **实时输出**：逐字符显示 AI 响应
- **工具调用**：显示所有工具调用记录
- **执行统计**：
  - 成本：API 调用成本（美元）
  - 耗时：总执行时间（毫秒）
  - 轮次：对话轮数

## 🔧 API 接口

### POST /api/v1/debug/skill/stream

流式调试单个技能

**请求体：**
```json
{
  "skill_name": "todo-master",
  "skill_content": "# 技能内容...",
  "test_query": "测试问题"
}
```

**响应格式：**
```
data: {"type": "session_start", "session_id": "debug_xxx"}

data: {"type": "data", "data": {"type": "assistant", "content": [...]}}

data: {"type": "data", "data": {"type": "result", ...}}

data: {"type": "session_end", "session_id": "debug_xxx"}
```

### POST /api/v1/debug/scenario/stream

流式调试场景（多个技能组合）

**请求体：**
```json
{
  "scenario_name": "数据分析助手",
  "skills": [
    {"name": "data-analysis", "content": "..."},
    {"name": "echarts_chart", "content": "..."}
  ],
  "test_query": "分析这个数据"
}
```

## 🎯 调试最佳实践

1. **从简单查询开始**
   - 使用简单明确的问题测试技能
   - 逐步增加复杂度

2. **关注工具调用**
   - 查看技能是否正确调用工具
   - 验证工具参数是否正确

3. **检查执行成本**
   - 优化技能以减少 API 调用
   - 平衡响应速度和质量

4. **迭代优化**
   - 根据调试结果调整技能内容
   - 重新测试直到满意

## 📝 示例

### 测试 TodoWrite 技能

**技能名称：** `todo-master`

**技能内容：**
```markdown
# Todo Master - 专业待办事项管理技能

你是 Todo Master，一个专业的待办事项管理专家。

## 核心能力

1. 任务规划与分解
2. TodoWrite 工具使用规范
3. 任务分解最佳实践
...
```

**测试查询：**
```
帮我规划一个学习 Python 的任务计划
```

**预期结果：**
- 工具调用：1 次（TodoWrite）
- 响应内容：结构化的学习计划
- 执行统计：成本约 $0.10，耗时约 50 秒

## 🐛 故障排除

### 问题：调试卡住不动

**解决方案：**
1. 检查网络连接
2. 查看浏览器控制台错误
3. 重启调试（刷新页面）

### 问题：工具调用失败

**解决方案：**
1. 检查技能内容中的 allowed-tools 配置
2. 确保工具名称拼写正确
3. 查看后端日志获取详细错误信息

### 问题：响应为空

**解决方案：**
1. 确保测试查询清晰明确
2. 检查技能内容是否完整
3. 尝试简化测试查询
